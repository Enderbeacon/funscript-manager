## Scripts in other folders

A script no longer has to sit beside its video.

- A script named exactly like a single video in the library is linked to it on its own, whichever folders the two are in.
- **Libraries → Match scripts** lists scripts whose names are close to a video's, or fit more than one video. Choose the video for each and link them all at once.
- Scripts can also come from folders outside the library, even on another drive. Linked scripts are copied into the library, so they keep working when that drive is unplugged.

## Large libraries open sooner

- A library shows its videos right away while its folders are checked in the background.
- Folders that haven't changed aren't read again, which helps most on external drives.
- If a drive is unplugged or a folder can't be read, the scan stops and the library keeps its entries.
- Each library card has a **Rescan** button. It also brings back a library whose drive was unplugged when the app started.

## Smoother playback

- Devices on the built-in player stay in step with video played in the app. A late position update no longer pulls the script back, and seeking, pausing and speed changes take effect at once.
- A brief stall in the app is no longer taken for a seek, so the device doesn't ease in again for no reason.
- Heatmaps line up with the video from start to end, stay blank where nothing moves, and show the script version that is playing.

## Improvements

- A video's detail card can play it next, add it to the queue or add it to a playlist, without finding it in the list first.

## Fixes

- A `.funscript` file that holds several axes now plays all of them, not just the main one, through the built-in player and through MultiFunPlayer.
- The merge window opened from a detail panel is no longer cut off, and Esc closes only the merge window.
- The expanded sidebar is no longer hidden behind an open player or panel.
- Downloads from a video site that changed its download menu work again.
- Suggested videos for an item awaiting its file follow the script matching setting, and merging the item keeps its rating and notes.
