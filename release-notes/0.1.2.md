- **Pinned tags**: pin a tag to get a one-click filter for it above the library. Pinned tags also sit at the top of the tag list in the filter sidebar.
- **MEGA**: built-in MEGA downloads are much faster, and the number of connections can be set in Settings. To use your MEGA account's transfer quota, install MEGAcmd from the new MEGA card and download through it.
- **Captchas in a row**: when a host asks for a captcha on every file, solving one opens the next file's captcha right away.
- **Fixes**: with more than one library, scrolling no longer shows some videos twice, skips others, or gets stuck. A video site that kept repeating its browser check now lets you through, and its downloads work again.
- **Try the VR panel**: a panel for browsing and playing from inside SteamVR is out on the beta channel. To try it, set Settings → Updates → Channel to Beta.
