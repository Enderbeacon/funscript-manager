## Downloads from 26 more video sites

Paste a link from any of them and it downloads into your library like the sites already supported, with the site shown on the link's badge.

- Videos in an X post download too. A post carrying several becomes one job per video.
- A page from a site nothing here knows is now tried through yt-dlp first, which finds the player on many unnamed sites.
- A profile, channel or search page is turned down rather than downloaded whole.
- Two more sources can be signed into, for videos that need an account.

## Improvements

- **Serial ports** are chosen from a list of the machine's ports instead of typed. One that is no longer plugged in stays on the list, marked as missing.
- **The Updates card** shows what the running version brought when there is nothing to install, and re-checks right away when you switch channel.

## Fixes

- The question about which video a script belongs to can be answered, and is asked once per script set rather than once per file.
- A main script dropped beside its axis files joins their version instead of starting one of its own.
- Opening a card's extra fields in Settings no longer pushes the cards beside it down the page.
- The speed limit's mode is readable again instead of squeezed to one letter.

## Trying the VR panel

Browsing and playing from inside SteamVR is out on the beta channel. To try it, set Settings → Updates → Channel to Beta.
