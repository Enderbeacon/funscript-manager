The app can now update itself.

- **Updates** live on the About page: the version you are on, stable or beta, and a check that offers whatever is newer. Downloading and restarting happen from there, and an older release can be installed the same way.
- **Release notes and notices** are shown once each, so you know what changed after an update.
- **Going back a version is safe.** A build older than the one that wrote your files no longer drops what it does not recognise, and a file it cannot read is kept rather than replaced.
