## Metadata files out of your folders

Each video's `.meta.json` file used to sit beside it. A library can now keep them together in its own hidden `.fsmgr` folder instead, so the folders you sort by hand hold only videos, scripts and subtitles.

- Choose it per library on the **Libraries** page. The files already there move over in the background, and the library works as usual meanwhile.
- **Settings → Library** sets where new libraries start.
- A folder outside the library can be used too, as an experimental option.

## Improvements

- The `.fsmgr` and `.fsmgr-cache` folders in each library are hidden in Explorer.
- Library cards on the Libraries page are laid out in two columns: the library's settings, and its entries.
